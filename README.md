#### Mediapipe build instructions
cd ~/shrinivas/o-test/face
# 1. Fetch the pinned MediaPipe source
./scripts/fetch_mediapipe.sh
# 2. Build libFaceMediaPipe.so using Bazel
./scripts/build_mediapipe.sh
# 3. Package the library and generate MANIFEST.txt
./scripts/package_mediapipe.sh

These will create
face/dist/mediapipe/linux-aarch64/
├── libFaceMediaPipe.so
└── MANIFEST.txt

cmake -S . -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DOpenCV_DIR=/usr/local/opencv-4.8.0-contrib/lib/cmake/opencv4 \
  -DFACE_ENABLE_MEDIAPIPE_RUNTIME=ON \
  -DFACE_MEDIAPIPE_PACKAGE_DIR="$PWD/dist/mediapipe/linux-aarch64"

cmake --build build -j2

ctest --test-dir build --output-on-failure

./build/yunet_demo --backend=mediapipe

Run each step only after the previous one succeeds. The initial bridge build needs internet access, Bazelisk with the pinned Bazel version, and the development dependencies; it takes substantially longer than the application build.

MANIFEST.txt is generated by the packaging script after checking the library’s architecture, dependencies, and exports. You don’t need to create it manually. Subsequent application-only changes can reuse this package.
